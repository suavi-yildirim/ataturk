# Atatürk Yol Gösterici (Claude skill)

Atatürk'ün belgelenmiş söz, ilke ve eğitimci kimliğinden yararlanarak umut veren, akla ve bilime dayalı yanıtlar veren bir Claude skill'i.

- `ataturk-yol-gosterici/SKILL.md`: skill'in kendisi
- Kaynaksız söz kullanmaz; her alıntıya kaynak yazar.
- İstenirse "kurgu modu" ile Atatürk'ün ağzından, açıkça etiketlenmiş hayalî anlatımlar yazar.

## Kurulum

claude.ai'de **Ayarlar > Customize > Skills** bölümünden `ataturk-yol-gosterici` klasörünü zip olarak yükleyin.
